# Ejercicios de Fundamentos de Python

## Descripción

Repositorio que contiene ejercicios prácticos realizados durante mi formación en Python.

Estos ejercicios están orientados a reforzar los conceptos básicos del lenguaje y mejorar la lógica de programación mediante actividades progresivas.

## Tecnologías utilizadas

- Python 3
- Jupyter Notebook

## Conceptos trabajados

- Variables
- Tipos de datos
- Strings
- Concatenación
- Slicing
- Índices
- Función len()
- Manipulación básica de cadenas

## Objetivo

Practicar los fundamentos de Python y afianzar los conceptos necesarios para avanzar hacia proyectos más complejos.
